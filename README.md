# Restaurante App - Semana 13

## Descripción
Aplicación modular en Python utilizando Tkinter para la interfaz gráfica de usuario (GUI), aplicando arquitectura en capas.

## Estructura
- `datos/`: Archivos JSON de persistencia local.
- `modelos/`: Definición de clases Usuario y Producto.
- `servicios/`: Carga de datos y lógica de validación.
- `ui/`: Vistas gráficas (LoginView y MainView).
- `main.py`: Punto de entrada y gestión de la ventana principal.

## Instrucciones de Ejecución
```bash
python main.py
